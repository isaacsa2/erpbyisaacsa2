# Gestão Ágil — mini-backlog da turma

## Objetivo

Evoluir o ERP educacional em pequenas entregas verificáveis. Organize um quadro no GitHub Projects com as colunas **Backlog → Em andamento → Em revisão → Concluído**.

| Issue | História de usuário | Critérios de aceite |
| --- | --- | --- |
| EDU-01 | Como operador quero ver estoque baixo | Mostrar apenas produtos com `stock < 10`, sem alterar dados |
| EDU-02 | Como professor quero verificar regras SQL | Passar todos os testes de `tests/test_exemplos.py` |
| EDU-03 | Como caixa quero impedir venda sem estoque | Não permitir estoque negativo e apresentar mensagem clara |
| EDU-04 | Como administrador quero exportar relatório | Exportação CSV só de dados fictícios, com cabeçalhos |

**Definition of Done:** código revisado, testes documentados, demonstração reproduzível, nenhuma credencial ou banco enviado ao Git e PR com explicação do problema e solução.

**Cerimônias sugeridas:** planejamento de 10 min, acompanhamento de 5 min e retrospectiva após cada exercício.
